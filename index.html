LabReady A4

Print-ready lab record layout tool. 100% client-side, works offline, no sign-up. Paste, drop or pick images, pack them onto one true-scale A4 sheet, then print or save as PDF.

Printing

Paper A4, scale 100%, margins None, Background graphics on. Use Chrome or Edge for the cleanest PDF.

Deploy to GitHub Pages

  1. Create a new Public repository on github.com, for example labready-a4.
  2. Click Add file > Upload files, drag in this single index.html, and commit.
  3. Go to Settings > Pages. Source: Deploy from a branch, Branch: main, folder / (root). Save.
  4. After about a minute your app is live at https://YOUR-USERNAME.github.io/labready-a4/.
  5. Paste that link into the repo's About > Website field.
